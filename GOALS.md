# Goals

## V.001 goal

Demonstrate that Meridian can turn synthetic order-fulfillment events into transparent efficiency findings.

## In scope

- Synthetic order data
- Order-level event timelines
- Fulfillment cycle time
- Waiting time between activities
- Rework detection
- Late-shipment detection
- Department-level comparison
- Evidence-backed opportunity cards
- Portable local launch

## Out of scope

- AI recommendations
- Real company data
- External integrations
- User accounts
- Automated actions
- Production deployment
